Install & first login

Five steps, about two minutes.

1

Download the APK

Use the button or QR above. The file is about ~50 MB.

2

Allow installs

Android will ask permission for your browser to install apps — tap Allow. This is normal for apps installed outside the Play Store.

3

Install & open

Tap the downloaded file, then Install. Find the Alumni Connect icon and open it.

4

Join the demo network

Connect to the same WiFi as the demo server (announced on defense day). The app talks to the school server over the local network.

5

Log in

Sign in with your student account. Forgot your password? Use the in-app reset flow.

Common questions

Is the app free?

Yes — completely free for students and alumni. There are no ads, no in-app purchases.

Which phones are supported?

Android 8.0 and newer. iPhones aren't supported by direct download (Apple only allows App Store installs) — ask us for a guided demo instead.

Why must I be on the same WiFi?

For the defense demo, the app connects to the school server running on the local network. It needs the same WiFi to reach it. A public release would connect over the internet instead.

Is “install unknown apps” safe?

You're installing our signed APK directly instead of via the Play Store — that's why Android asks. Only install the file from this page or the official QR, never from forwarded copies.

Is my data safe?

Logins use token-based authentication, passwords are never stored on the phone, and all records live in the school's secured database — the same one the admin office uses.
